## 📊 **РАСЧЕТ ДЛЯ ПРЕПОДАВАТЕЛЯ**

**Формула:** `ДЖЕЛ (л) = (0.043 × Рост) - (0.015 × Возраст) - 2.89`

**Данные:**
- Рост = 120 см
- Возраст = 5 лет (фиксировано для демо)

**Расчет:**
```
ДЖЕЛ = (0.043 × 120) - (0.015 × 5) - 2.89
     = 5.16 - 0.075 - 2.89
     = 2.195 литра
```

**Объяснение:** "Система автоматически рассчитывает теоретическое значение ДЖЕЛ 2.195 л для ребенка ростом 120 см по формуле для мальчиков 4-7 лет. Этот результат можно сравнить с фактически измеренным значением для диагностики."

---

## 💡 **ВАЖНЫЙ МОМЕНТ ДЛЯ ДЕМОНСТРАЦИИ**

**Покажите разницу состояний:**

1. **До завершения:** `final_result = 0` (расчет еще не выполнен)
2. **После завершения:** `final_result = 2.195` (ДЖЕЛ рассчитан)

**Это демонстрирует бизнес-логику:** расчет происходит только при завершении заявки модератором, а не при вводе данных.
